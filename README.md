# PIZNO · демо застосунку прокату авто

Інтерактивний прототип мобільного застосунку для прокату авто (українською). Статичний сайт: `index.html` + зображення, без збірки.

- Каталог за класами: Економ / Комфорт / Бізнес / Еліт, 21 авто з орієнтовними цінами для Києва
- Бронювання: календар доступності, тарифи за тривалістю, опції, анкета клієнта
- Лояльність: токени, рівні клієнта, подарункові сертифікати з онлайн-листівкою
- Панель власника з демо-даними

Бренд задається однією константою `BRAND` у скрипті `index.html`.

## Фото авто

Фото з Wikimedia Commons, фон вирізано, номерні знаки замінено на брендовані. Автори та ліцензії (CC BY-SA 4.0, CC BY 2.0, CC0) — у `cars/credits.json` і в застосунку (Профіль → Фото авто).
